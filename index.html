پرسش‌های پرتکرارFAQ

کلید من روی چند ماشین کار می‌کند؟How many machines does my key work on?

روی همان یک ماشینی که کد سخت‌افزاری‌اش را فرستادید. کلید لو رفته روی ماشین دیگر اجرا نمی‌شود. باندل ۵ ماشینی = پنج کلید جدا.Only the one machine whose hardware code you sent. A leaked key won't run elsewhere. The bundle = five separate keys.

اگر قطعه‌ای از سخت‌افزار را عوض کنم چه؟What if I replace a hardware part?

تعویض یک قطعه (مثلاً کارت شبکه) لایسنس را باطل نمی‌کند؛ تعویض کل ماشین یعنی کد جدید و کلید جدید.Replacing one part (e.g. the NIC) keeps your licence; replacing the whole machine means a new code and a new key.

برای فعال‌سازی اینترنت لازم است؟Does activation need internet?

هرگز. صدور و بررسی کلید ۱۰۰٪ آفلاین است؛ هیچ سرور واسطی در مسیر نیست.Never. Issuing and verifying keys is 100% offline; no middle server anywhere.

تفاوتش با Speedify چیست؟How is it different from Speedify?

Speedify اشتراک ماهانه دارد و ترافیک از ابرشان می‌گذرد؛ NetBond یک‌بار خرید است و ترافیک هرگز از سرور ثالث نمی‌گذرد.Speedify is a monthly subscription routing via their cloud; NetBond is one-time and no third server ever touches your traffic.

نسخهٔ آزمایشی چه محدودیتی دارد؟What are the trial limits?

هیچ محدودیت قابلیتی نیست؛ فقط ۴۸ ساعت. بعدش با کلید، همان برنامه کامل می‌ماند بدون حذف نصب.No feature limits; just 48 hours. Afterwards a key upgrades the same install, no reinstall.
